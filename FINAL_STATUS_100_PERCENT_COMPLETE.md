```
Add Movie → Validate Release Date

Status Logic: Future→Scheduled, Today+Future→Scheduled, Today+Past→Running, Past→Completed
```

### 4. ✅ User Booking Flow (Complete Journey)
```
Browse Theaters → Select Hall → View Shows → Select Seats
→ Review Booking → Submit Payment → Admin Approval → Ticket Issued
```

### 5. ✅ Payment Processing
```
User Submits Payment (Status: Pending)
→ Admin Reviews
→ Admin Approves (Status: Paid) → Ticket Generated
OR Admin Rejects (Status: Failed) → Refund Process
```

### 6. ✅ Ticket Generation
```
After Payment Approved → Ticket Created
→ Displays All Details (Movie, Seats, Date, Time, Price)
→ Available for Print/Download
→ Added to User's My Bookings
```

### 7. ✅ Booking Cancellation
```
User Initiates Cancel → Status: Cancelled
→ Seats Released Back to Available
→ Refund Processed
→ Confirmation Email Sent
```

### 8. ✅ Admin Dashboard
```
Theater Management → Movie Management → Show Management
Payment Approvals → Ticket Issues → Reports & Analytics
```
